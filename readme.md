# 项目简介

项目是一个混合类型的项目，包含了前端、后端、数据库等组件。
注意gitignore的管理按文件夹分别进行。

# 文件夹说明

1. ai-agent
    定时夜间检查用户是否更新的文档，做新文档的整理工作，整理的目的是为提示词服务
2. ForClient
    提供给用户使用，可自行设置更新文档
3. ForManage
    提供给机器人的管理者使用，可做机器人版本管理和配置
